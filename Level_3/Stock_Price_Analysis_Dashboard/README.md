# 📈 Stock Price Analysis Dashboard – Power BI

## 📖 Project Overview

This project presents an interactive **Stock Price Analysis Dashboard** developed using Microsoft Power BI.

The dashboard analyzes stock market data to provide a clear view of stock prices, trading volume, company-wise performance, and price trends over time.

The dashboard is designed as a **single-page business intelligence report**, allowing users to quickly monitor key stock performance indicators and explore the data using interactive filters.

---

## 🎯 Business Scenario

Investors, analysts, and business stakeholders need a simple way to monitor stock performance and identify price trends across different companies and time periods.

Raw stock market data can contain thousands of daily records, making it difficult to quickly identify important patterns.

A Power BI dashboard can transform this raw data into an interactive visual report that supports faster analysis and decision-making.

---

## ❓ Business Question

**How can stock market data be transformed into an interactive dashboard that helps users analyze price trends, compare companies, and monitor trading activity over time?**

---

## 🎯 Dashboard Objectives

- Monitor key stock price indicators.
- Analyze stock price trends over time.
- Compare stock performance across companies.
- Analyze trading volume.
- Examine highest and lowest stock prices.
- Allow users to filter the analysis by company.
- Allow users to analyze data across different dates.
- Present important information through interactive Power BI visuals.

# 📊 Dashboard Components

The dashboard contains several visual elements designed to provide different perspectives of stock performance.

### KPI Cards

The dashboard includes KPI cards for monitoring important stock metrics such as:

- Stock / Company information
- Closing Price
- Highest Price
- Lowest Price
- Trading Volume

These cards provide a quick summary of the selected data.

---

### 📈 Stock Price Trend

A line chart is used to analyze stock price movement over time.

This helps users identify:

- Upward trends
- Downward trends
- Price fluctuations
- Changes in stock performance over time

---

### 📊 Company-wise Analysis

Bar and column charts are used to compare stock-related metrics across companies.

This allows users to identify differences in performance and trading activity between companies.

---

### 📊 Trading Volume Analysis

Trading volume is visualized to understand the level of market activity associated with different stocks.

Higher trading volume can indicate greater market activity during particular periods.

---

### 🎛️ Interactive Filters

The dashboard contains slicers for:

- **Date**
- **Company / Symbol**

Users can select a specific company or date range to dynamically update the dashboard visuals.
