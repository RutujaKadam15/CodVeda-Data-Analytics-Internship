## 📖 Overview

This repository showcases the projects completed during my **Codveda Technologies Data Analytics Internship**. The internship focused on applying data analytics and machine learning techniques to solve real-world business problems using Python, SQL, and Power BI.

The projects cover the complete data analytics lifecycle, including data cleaning, exploratory data analysis, predictive modeling, machine learning, and business intelligence dashboard development.

# 📊 Internship Projects

## 📁 Level 1 – Data Analysis Fundamentals

### 🔹 Task 1 – Data Cleaning & Preprocessing
- Dataset: Iris Dataset
- Cleaned and prepared raw data for analysis
- Removed duplicate records
- Checked missing values
- Verified data quality
- Prepared dataset for machine learning

### 🔹 Task 2 – Exploratory Data Analysis (EDA)
- Dataset: Iris Dataset
- Performed descriptive statistics
- Explored feature relationships
- Created visualizations
- Identified trends and patterns

---

## 📁 Level 2 – Machine Learning

### 🏠 House Price Prediction
**Task Type:** Regression Analysis

Built a regression model to predict house prices based on property characteristics and evaluated model performance using regression metrics.

### 👥 Customer Churn Prediction
**Task Type:** Classification Analysis

Developed a machine learning model to predict customer churn and identify customers at risk of leaving the business.

---

## 📁 Level 3 – Advanced Analytics

### 📈 Customer Churn Predictive Modeling

Designed and evaluated predictive models to forecast customer churn, compare model performance, and generate business recommendations for improving customer retention.

### 📊 Stock Price Analysis Dashboard

Developed an interactive Power BI dashboard to analyze stock market performance using KPIs, trend analysis, trading volume, and company-wise comparisons.
